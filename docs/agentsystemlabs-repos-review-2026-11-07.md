# AgentSystemLabs repos vs Aico (2026-11-07)

Assessed at aico 20eb0520 against shallow clones of each repo's default branch (read only; nothing installed, built or run; clones deleted afterwards). Box Yard is covered in `docs/box-yard-comparison-2026-11-07.md`. Every idea below is judged on design, value, cost and upkeep against Aico's code, not on stars or age.

## 3. Worth building, by value per effort

1. **Session label from the agent's own terminal title** (small). When a session has no typed name, Tether reads tmux `#{pane_title}`, strips the leading status glyph and shows it as the task in the session list and header; a typed name always wins. Lands in Tether's session descriptor and `packages/web-server/src/sessions.ts`. Check what Codex and Pi set; if they set nothing, keep the default label.
2. **Two coding-practice lines** (tiny). Add to the coding practice prompt: "When you change a shared contract, list every consumer and producer, including unchanged files, and update or check each" and "Name the 1 to 3 properties that define the feature and test those first." Use `st prompt update`, measuring before and after.
3. **Answer agent questions with taps** (medium). Add a `PreToolUse` matcher for AskUserQuestion to the agent-state hook so the questions and options ride on the blocked session. Needs you shows them as buttons, and the answer goes in as arrow, Space and Enter keys through Tether input. If the menu doesn't match, fall back to the terminal. Later: Claude's permission prompt (Yes / No) and Codex's `request_user_input` the same way.
4. **Read-only Changes in Files** (medium). Git status for the session's folder and a per-file diff against HEAD, on phone and desktop. No commit or discard.
5. **Fake agent for tests** (small to medium; same as box-yard #5, smaller). A script named `claude` on the test PATH that writes `~/.claude/sessions/<pid>.json` (busy, waiting, idle) driven by trigger words, so Needs you, Finished and stuck states can be tested without a real agent.

How this lines up with the Box Yard list:
- **Continue with another harness**: none of these repos has it. Box Yard's design stays the reference.
- **WIP safety ref to the peer host**: nothing new. Agent-office's "never delete a worktree holding unpushed work" (`src/server/leave-on-merge.ts`, `prune.ts`) is the same rule Box Yard has.
- **Transcript secret redaction**: nothing new. Mission Control only redacts query-string secrets in error text (`src/server/api-router.ts:145`).
- **Spend by project**: smaller than the Box Yard doc says. Aico already records tokens per day, model and project for Claude and Codex (`packages/usage/src/claude-transcripts.ts`, `codex.ts`). What's left is role tagging and showing it on Quota. Claude's `cost-state` line is the ground truth if dollars are wanted.
- **Fake agent for tests**: both nebula and agent-office back it up, and show that a tiny script on PATH is enough (item 5).
