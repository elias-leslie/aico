Scope:
1. Resume and branching: a run continues from its SQLite transcript, and a branch forks at a given turn. `aico agent run --resume ID` and `--branch ID@TURN`.
2. Compaction: wire Pi's compaction in unchanged, triggered the way Pi triggers it. Tests show a long transcript compacts and the run continues.
3. Turn-level fallback: when a turn fails with a provider error (not a refusal or a tool error), the next model in `route()`'s chain takes that turn. Log and show which model ran each turn. Refusals keep M6b's typed handoff.
4. Headless role lanes under Tether: `aico agent run --role ROLE` can be started as a Tether session, so it shows in sessions and Status like the other tools, with its tokens and tool count in M8-2's store.
5. Hunting role: a role policy with no Claude models and an egress profile (which hosts it may reach). Define the role and prove its policy fails closed: a Claude model or a host outside the profile is refused. Don't run a hunt, and never open the neri repo or Neri data.

Proof:
- Tests for resume, branch, compaction, the fallback rule (provider error vs refusal vs tool error), the role policies and the hunting egress refusal.
- `st check --quick --changed-only`, and `st check --acceptance` before and after.
- Deploy: `st sessions may-disrupt`, then `st service rebuild aico --detach` (with `--worker tether@default` if Tether changes). Other builders deploy too, so before any restart check `st lease --list --all` for a `deploy` hold, take `st lease --hold 'deploy'` for the restart, and release it after.
- Live: a short `aico agent run` on a non-Claude model in a scratch folder, resumed once, branched once, and shown in `aico sessions show` with tokens and tools. Force one fallback (an unreachable first model) and show the second model took the turn.
