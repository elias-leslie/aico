Scope:
1. `aico web search|fetch|batch|refocus` with the same flags and output shapes agents use today, so `st web` can delegate mechanically. Each call increments a counter, shown as a Status row (calls today, failures, fallback use).
2. Ask-a-model: `aico ask MODEL "question" [--schema FILE] [--files ...]` routes through `route()` and runs on `agent` headlessly, for Codex, agy and Claude (`claude -p`, tools off). With `--schema`, the answer is validated JSON. No tools by default, a short timeout bound only on wire silence (5 min, as the rule says), and a typed failure.
3. Cutover: `st web` becomes a thin call into `aico web` through SummitFlow's delegation seam (`summitflow/backend/cli/lib/aico_delegate.py`), with rollback as M10a-2 did. Also update the `web-research` skill text if its commands change.
