# M3 brief (builder: Opus 5.5 high, native subagent)

Goal: milestone M3 in /srv/workspaces/projects/aico, building two packages and an endpoint.
- `jobs`: the scheduler. A fenced SQLite lease table, a home machine per job kind, and one Status row per job.
- `notify`: the notice schema, Needs-you asks, the outbox, and the FCM sender.
- The OmniNull push endpoint, which accepts notices and Status rows from the OmniNull hub.

Afterwards the Nightshift web board/PWA, digest, Web Push, notify-critical and web unit can be stopped once M4 is also done. Stopping them is not this milestone.

  - 2.3 rows ns-26, ns-30, ns-20, ns-08, ns-11, ns-39 and ns-17 (dropped), with their data columns.

Scope:
1. `contracts/notice.schema.json` and fixtures, compatible with the notice JSON the OmniNull hub and Nightshift send today. Read the shape from the Nightshift sources; don't break the hub.
2. `notify`:
   - notice store and log in its own DB;
   - an outbox that is the one deliverer: retries with backoff, never sends twice, and has a Status row;
   - an FCM sender in TS. Token minting stays a small Python piece in host-steward per ns-20. Never read or print key material; use the existing credential file paths through config.
   - Needs-you: a failing Status row may raise one ask. Reuse Tether asks; no second ask store.
3. `jobs`:
   - a fenced lease table (lease id plus fencing token; a stale holder's writes are refused);
   - a home machine per job kind, as data;
   - takeover when the lease expires;
   - one Status row per job, with `next_run`;
   - a new `aico-jobs.service` user unit, deployed like the others;
   - first jobs: move the existing aico timers that fit, such as the notes export, if that is the smallest real proof. Otherwise one real job.
4. OmniNull push endpoint in web-server: accepts notices and Status rows from the hub, authenticated by the means the hub already uses or the smallest pinned-key scheme. Reached only on the LAN or loopback, never the internet. "That was me" goes back through the hub's verdict route.

  - a hub-shaped notice POSTed to the endpoint lands in the notify log.
