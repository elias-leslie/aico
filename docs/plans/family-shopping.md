# Family Shopping integration

The complete owner-approved scope and acceptance matrix are in Portfolio AI's
`docs/SHOPPING_PLAN.md` at `/srv/workspaces/projects/portfolio-ai`. Dadbot is the
family Shopping interface; Portfolio keeps canonical items, source evidence and
prices. Aico supplies subscription image/file models, public research and repair.

This checkpoint removes dedicated Aico grocery shortcuts, preserves Notes history,
and directs new shopping captures to Dadbot without claiming to transfer files.
It correlates opaque Shopping request IDs across all three applications and routes
verified software/provider faults to the responsible project's repair agent.
Repairs preserve original evidence and edits, consult a peer when needed, use an
isolated deployed-base checkout, pass the full gate, release the accepted commit,
and replay the original job. Only actual successful work clears a failure.

Gemini is primary. Subscription fallbacks must be currently eligible without
buying credits; private inputs never use public-only Gemini free-tier research.
Off machines remain off. Credentials, financial approvals, durable-data deletion
and publication remain owner decisions.

Verification includes model-image transport, fallback eligibility, attributed
fault reporting, correct-project repair routing, release/replay checks, preserved
Notes history, and rendered capture/Notes navigation. Portfolio's full matrix
also requires live receipt reconciliation and Terra/Luna user journeys in Dadbot.
